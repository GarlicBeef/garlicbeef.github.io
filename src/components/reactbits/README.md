Components in this folder come from React Bits (https://reactbits.dev, github.com/DavidHDev/react-bits),
TypeScript + CSS variants, by David Haz. Licensed MIT + Commons Clause — usable inside this website,
not for redistribution as standalone components.

- OptionWheel.tsx / OptionWheel.css — curved year selector in Research (locally extended: scroll-driven, no wheel capture; see header comment)
- FluidGlass.tsx / FluidGlass.css — WebGL liquid-glass lens (About page, over `public/hero.jpg`)
